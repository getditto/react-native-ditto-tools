react-native-ditto-tools 2 supports Ditto React Native SDK 5 and requires `@dittolive/ditto` 5.0.1 or a later 5.x release.

## Breaking changes

- Ditto React Native SDK 4 is no longer supported.
- Tools peer and connection data use the Ditto 5 field names: `isConnectedToDittoServer`, `peerKey`, `peer1`, and `peer2`. (SDKS-3821)
- `SystemSettingsProps` and `SystemSettingsStyles` were removed because they did not describe the component's actual props. `SystemSettings` continues to accept `ditto` and optional `style`.

## Changed

- Removed obsolete SDK 4 transport configuration and `DITTO_WEBSOCKET_URL` example settings. (SDKS-3929)
- Updated the example app to use the Ditto 5 initialization and authentication APIs.
- The example project was upgraded to React Native 0.81.5 and CLI 20.1.3. (SDKS-3157)
- Updated the package support URL to `https://support.ditto.com`.
